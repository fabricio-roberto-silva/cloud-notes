# cloud-notes

Practical notes and guides on **Oracle Cloud (OCI)** and **Microsoft Azure**.

## Scope / Escopo
- OCI: compute, networking, storage and IAM basics / noções de computação, rede, armazenamento e IAM
- Azure: virtual machines, networking, identity and DevOps / máquinas virtuais, rede, identidade e DevOps
- Cost awareness and good practices / Controle de custos e boas práticas
- Backup and availability concepts / Conceitos de backup e disponibilidade
